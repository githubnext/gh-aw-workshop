# Install the gh-aw CLI Extension

`gh-aw` is the CLI extension that compiles your [agentic workflow](https://github.github.com/gh-aw/introduction/overview/) Markdown files and triggers runs from your terminal.

## 📋 Before You Start

- You have completed [Agentic Workflows Intro](05-agentic-workflows-intro.md)
- Your Codespace is ready

## Continue in your Codespace

The core workshop installs `gh-aw` in your Codespace so every learner uses the same environment.

If you chose to manage your own machine, take the optional [Install `gh-aw` in a Local Terminal side quest](side-quest-06-04-install-local.md).
